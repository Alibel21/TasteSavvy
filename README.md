# 知味TasteSavvy | 校园食堂窗口决策智能体Your AI agent for smarter choices at campus canteen counters.

> 不再纠结吃什么！

**参赛者：** 毕立芙

## 一、项目简介（200 字以内）

食堂窗口在学生端存在严重的信息缺口——菜单无图且缺乏横向对比，就餐犹如开盲盒。为此，我们开发了校园食堂窗口决策智能体【知味】。
针对学生课业疲惫时“不想思考、只想快速吃饱”的痛点，产品通过拍照识别与同义词搜索，将孤立的物理窗口转化为包含菜品、价格与评价的结构化服务节点；并结合口味偏好、人气数据等直接生成推荐，大幅减轻点餐负担。
这让大量未被数字化的物理服务节点，首次可被智能体有效调用。

## 二、功能

- **拍照识别窗口**：在搜索框右侧点 📷 上传窗口照片，Ling 模型读出招牌文字，页面列出候选窗口，用户点选确认后进入窗口页。识别失败时可直接搜索窗口名。
- **窗口页**：列出该窗口所有菜品，可点赞、收藏、写评价；每道菜右上角有标识（本窗口点赞最高、收藏最多、评价最多、猜你喜欢），并可按综合推荐、点赞、收藏、评价排序。
- **搜索**：支持食堂名、窗口名、菜名、口味词（清淡、辣、素等，含"不油腻"等同义词），多个关键词用空格隔开；搜菜名会列出各窗口的同类菜，便于横向比较。
- **菜品详情页**：该菜的点赞、收藏数和评价。
- **随机推荐**：点首页按钮随机给出一道菜，带"👍 喜欢 / 👎 不想吃 / 换一个"；根据点赞、收藏和反馈更新口味偏好，推荐倾向于"口味相近但没吃过"的菜；单点吃不饱的菜（小食）自动搭配同窗口的主食。

当前收录颐三食堂 5 个窗口 141 道菜、颐一食堂 6 个窗口 44 道菜，菜单与价格由参赛者实地整理。

## 三、运行环境与方法（Windows）

- 需要 Python 3（只用标准库，无需安装其他依赖）。
- 复制 `config.example.json` 为 `config.json`，填入自己的 API Key（该文件不会也不应提交到仓库）。
- 在本文件夹打开命令行，运行 `python server.py`，浏览器访问 `http://localhost:8000`。
- 不配置 API Key 时，也可直接双击 `canteen.html`，除拍照识别外的功能均可使用。

## 四、AI 模型与工具使用说明

| 用途 | 模型 / 工具 |
|---|---|
| 窗口照片识别 | 蚂蚁百灵 **Ling-3.2-flash**（通过赛事提供的 API，接口 `maas-api.antdigital.com`），由 `server.py` 转发，API Key 只保存在本机 `config.json` |
| 方案讨论、代码编写与调试 | **Claude**（Anthropic），与参赛者协作完成 |
| 前端 / 服务 | 原生 HTML + JavaScript；Python 标准库 `http.server` |

推荐、排序、标识均为规则计算，不调用大模型；大模型仅用于窗口识别。
